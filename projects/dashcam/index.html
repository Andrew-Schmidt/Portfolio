Linux Dashcam & Event Dashboard.

A vehicle recording system combining a Linux PC, phone video, a physical event button, and web access.

Why I built it

I wanted an affordable, serviceable recording system with the ability to protect important clips.

My approach

Developed a Linux-based dashboard and recording workflow, integrated an Arduino Leonardo input for event marking, and troubleshot recording and file-management issues.
