Why I built it

A one-off speed test misses intermittent issues. Repeated measurements and historical data help reveal performance variation and longer-term patterns.

My approach

Developed scheduled Speedtest CLI measurements, newline-delimited JSON logging, and a historical visualization dashboard. Exported sanitized daily summaries and recent individual measurements for a static public portfolio preview. Separately exploring a portable, gigabit-capable field tester.
