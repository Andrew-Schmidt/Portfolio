Inventory Management System.

A general-purpose web platform for organizing assets, capturing multiple photographs, and maintaining searchable inventory records.

Try the inventory demo

Explore a browser-only version of the inventory system. Search and filter items, create groups, edit descriptions, and attach temporary photos. All starter items are fictional; no production database or API is connected.

Launch interactive inventory demo →

Demo changes are temporary and reset on refresh. The real system uses Python/Flask and persistent storage; this preview is a static JavaScript recreation.

Why I built it

Cataloging hundreds of collection pieces required organized photos and an easy data-entry workflow.

My approach

Built a Flask application with group organization, multi-photo uploads, and API functionality; deployed behind Nginx and Gunicorn on Ubuntu with HTTPS. Developed an Android wrapper for hands-free Bluetooth-shutter photo capture.

What it demonstrates

This project reflects practical problem solving, independent learning, and applying technical concepts to working systems or prototypes. Its status is listed above so the scope of completed work is clear.
