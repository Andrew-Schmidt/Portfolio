Network Diagnostics Lab.

A Linux-hosted Flask dashboard for exploring network diagnostics, with an isolated public demonstration and private capture tooling.

Live public demoPersonal technical project
⇄ILLUSTRATIVE VISUAL · REPLACE WITH PROJECT SCREENSHOT

Why I built it

I wanted a browser-accessible way to explore network interfaces, packet captures, and diagnostic workflows without requiring users to operate Linux command-line tools directly.

My approach

Rebuilt and deployed the application on a dedicated Ubuntu EC2 instance, using Flask and Gunicorn behind an Nginx HTTPS reverse proxy. The public instance runs in demonstration mode, while privileged live-capture functionality is reserved for private use.

What it demonstrates

The deployment demonstrates application development, Linux service management, reverse proxy configuration, HTTPS, DNS, AWS networking, and designing safer boundaries between public demonstrations and privileged tools. Demo statistics are illustrative—not live measurements from a visitor’s network.
